# Mars\_fNIRS

These scripts and full fNIRS analysis are intended to be ran in MATLAB. Version 2024a was used for completion of this analysis. 

Within MATLAB:
Add Wavelet Toolbox through Home > Add-Ons > Get Add-Ons > Wavelet Toolbox > Install
